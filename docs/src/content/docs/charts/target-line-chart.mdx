`<a11y-target-line-chart>` is built around one question: **was the target met in the latest reported period?** The visible summary answers that before the reader explores the chart. The actual and target series differ in color, line style (solid or dashed), and point shape (circle or diamond), so the distinction never depends on color alone.

<ChartExample
	type="line"
	headingLevel={2}
	properties={{
		chartTitle: 'Preventive care visits',
		config: {
			valuePreset: 'percent',
			positiveDirection: 'above',
			baselineSeriesLabel: 'Plan start',
			showControls: false,
		},
		data: [
			{ x: '2021', actual: 64, target: 70 },
			{ x: '2022', actual: 68, target: 70 },
			{ x: '2023', actual: 73, target: 72 },
			{ x: '2024', actual: 77, target: 74 },
			{ x: '2025', actual: 81, target: 76 },
		],
		baseline: {
			x: '2021',
			value: 64,
			explanation: 'This is the first reporting year and the reference point for later comparisons.',
		},
		context: 'Completed annual preventive visits among eligible members (fictional data).',
	}}
/>

Readers can move between periods with the arrow keys, Home, and End on a single tab stop. When the chart overflows its container horizontally, Previous and Next buttons appear for touch.

## Data

Each row has an `x` period, an `actual` value, and a `target`. Use `null` for a missing actual value; the chart reports it as missing instead of drawing a zero.

`target` accepts a number, an inclusive `{ min, max }` range, or `null`, and the two kinds can be mixed:

```ts
chart.data = [
	{ x: 2024, actual: 72.5, target: 80 },
	{ x: 2025, actual: 75, target: { min: 70, max: 80 } },
	{ x: 2026, actual: null, target: { min: 72, max: 82 } },
];
```

For a numeric target, `config.positiveDirection` (`above` or `below`) sets which side counts as meeting it. A value equal to the target always meets it. A value meets a range when `min <= actual <= max`.

## Baseline

`baseline` adds an optional reference marker and line. Its `x` must match the earliest displayed period, and its `value` doesn't have to match that period's actual value. An invalid baseline emits `a11y-target-line-chart-error` with code `invalid-baseline`, and the chart still renders without it.

## Value scale

| Attribute | Config | Values | Default |
| --- | --- | --- | --- |
| `value-preset` | `valuePreset` | `percent`, `number` | `percent` |
| `percent-scale` | `percentScale` | `whole`, `fraction` | `whole` |

With `percentScale: 'whole'`, supply `45` for 45%. With `fraction`, supply `0.45`. The scale applies to `actual`, `target`, and `baseline.value`, and getters and events return values in the scale you supplied.

## Events

Besides the events every chart fires, the target line chart has `a11y-target-line-chart-point-change`, which fires when the reader selects a period and includes the announcement and outcome, and `a11y-target-line-chart-settings-change`, which fires when the reader changes a display setting. See [Events](/reference/events/) for every payload.
