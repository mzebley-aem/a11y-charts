## The charts

Each chart is a standard custom element that renders into the page's Light DOM. They work in any framework, or none, and every chart includes a summary, a complete data table, and CSV export.

<CardGrid>
	<Card title="Target line chart">
		Actual versus target over time. Answers one question first: was the target met in the latest
		reported period?
	</Card>
	<Card title="Bar chart">
		Horizontal category counts and population shares, with definitions, suppression, and grouped
		population views.
	</Card>
	<Card title="Segmented bar chart">
		The breakdown of a total, or a single value compared with a reference total.
	</Card>
</CardGrid>
